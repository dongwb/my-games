# 🎮 我的小游戏合集

纯 HTML/JS/Canvas 写的网页小游戏，**双击即玩，零安装零依赖**（街头萌战 2 需要带上 assets 文件夹里的贴图）。

## ⚽ 街头萌战 2 STREET CUP 2（street-cup-2.html）—— 主打

5v5 街头足球（含门将），萌萌二头身小人，八支世界杯风格球队各有"队魂"。

**单人操作**：方向键/WASD 跑 · C 蓄力传球 · X 蓄力直塞 · 空格蓄力射门（蓄力时 ←/→ 转瞄准）· 双击方向 = 爆趟突破

**双人同键盘**：P1 = WASD + C + X + 空格（黄箭头）｜P2 = 方向键 + K + I + L（青箭头）

**模式**：单场 / 八队锦标赛（淘汰赛，AI 之间自动模拟比分）/ 双人同键盘

**队魂**：阿根廷=防守反击 · 西班牙=控球 · 巴西=技术流 · 荷兰=高压 · 法国=均衡 · 日本=速度流 · 葡萄牙=边路 · 墨西哥=铁桶

特色机制：三档蓄力（太轻无力/正好/太冲会失控）、门将扑救+脱手拼抢、爆趟突破（球比人快）、完整开球规则、赛后技术统计表、真实音效、禁区清场 3 秒警告。

## ⚽ 街头萌战初代（street-cup.html）

3v3 小场版，v1.2.0 封盘保留作纪念。

## 🏎️ 霓虹狂飙 NITRO RUN（nitro-run.html）

伪 3D 公路赛车：三车道躲避、定速巡航、最高时速致敬陆地极速纪录。

## 🏁 极速弯心 APEX RACER（f1-apex.html）

俯视 F1：眼镜蛇赛道（大发卡弯 + 连续 S 弯 + 之字弯），向量物理 + 循迹刹车，
跟住前车吃**尾流**（极速 ×1.25）再超车。AI 难度三档（鼠标点选），
镜头近追/全景双视角，出赛道滑进草地自动复位。

**操作**：↑/W 油门 · ↓/S 刹车 · ←→/AD 转向 · V 切镜头
